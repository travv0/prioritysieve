# Reset Tags

![reset-tags.png](../../img/reset-tags.png)

If you adjust your note filters or rename tags, previously applied PrioritySieve tags can become misleading. The tags
shown above (`am-known-*`, ready/not-ready, etc.) are safe to remove because they are reapplied during Recalc.

To reset these tags, go to `Tools` -> `PrioritySieve` -> `Reset Tags`
