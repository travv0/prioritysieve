# Card Handling

![card-handling-tab.png](../../../img/card-handling-tab.png)

PrioritySieve handles entry collisions automatically during Recalc: when multiple new cards share the same entry, only
the highest-priority card is unsuspended and the rest are parked. The controls on this tab fine-tune that behaviour.

**On Recalc**:

* **Suspend cards whose entry is missing from priority files** – when enabled, cards whose entry does not occur in any
  selected priority file are automatically suspended.
* **Priority decks** – if you use multiple decks for the same entries, you can prioritise which deck should supply the
  active card. Decks higher in the list take precedence when two cards share an entry.
