# Extra Fields

PrioritySieve only maintains a single optional extra field: **ps-reading**. When enabled for a note type, the add-on
copies the reading that was chosen during Recalc into this field so you can display or search it easily.

> **Note**: The first time you enable an extra field for a note type you will need to perform a full sync upload to
> AnkiWeb.

To enable the field:

1. Open **Tools → PrioritySieve Settings → Extra Fields**.
2. Tick the note types that should receive the `ps-reading` field.
3. Finish configuring your filters, then run Recalc. The field will be added to those note types and populated with the
   selected reading.

No other extra fields are created in entry-first PrioritySieve.
