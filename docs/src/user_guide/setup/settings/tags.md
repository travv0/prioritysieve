# Tags

![tags-tab.png](../../../img/tags-tab.png)

As PrioritySieve processes cards, it automatically adds and removes various tags. You can customize the names
of the different tags if you want, or you can leave them as they are and move on.

> **Note:** Avoid reusing tags from other sources. Mixing different tags can quickly become complicated and confusing. 

* **Ready**:  
  Cards for entries that can be studied immediately receive this tag. PrioritySieve keeps one active card per entry, so
  this is the copy that stays unsuspended.

* **Not ready**:  
  Cards blocked by another card for the same entry keep this tag. Enable auto-suspend to have PrioritySieve suspend
  these duplicates automatically.
* **Known automatically**:  
  Cards whose entry was already reviewed when Recalc ran gain this tag. They are duplicates and can be safely deleted if
  you want to trim your collection.
* **Known manually**:  
  Cards you mark with “Set Known and Skip” receive this tag. Do **not** delete cards with this tag; PrioritySieve uses
  them to track which entries you know.
* **Suspended automatically**:  
  Cards that have been suspended with the [suspend new cards option](card_handling.md) carry this tag.
