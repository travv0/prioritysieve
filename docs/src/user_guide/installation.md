# Installation

You can download the latest version of PrioritySieve from [ankiweb](https://ankiweb.net/shared/info/472573498). You can
find previous versions [on github releases](https://github.com/mortii/prioritysieve/releases).

PrioritySieve 6 and later no longer depend on external morphemizers. Once the add-on is installed you only need to
configure the note filters that identify your entry field, optional reading source, and priority files. If you are
updating from an older, morph-based version you can safely remove any companion morphemizer add-ons such as
`ankimorphs-japanese-mecab` or `ankimorphs-chinese-jieba`—PrioritySieve now treats the targeted field as a single entry.

After installation, walk through the [setup guide](setup.md) to configure your note filters and options. Once that is in
place you can run [Recalc](usage/recalc.md) to build the entry database and start scheduling against your priority
lists.
